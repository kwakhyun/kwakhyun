## RelayGuard

원본 API 토큰을 클라이언트에 전달하지 않고, 접근 범위와 누적 호출 수, 응답 바이트를 제한한 키를 발급하는 셀프호스팅 HTTP 게이트웨이입니다.

Python/FastAPI와 SQLite로 구현한 MIT 오픈소스이며, 현재 v0.2.0 공개 시험판입니다. Docker로 실제 서비스 토큰 없이 합성 데이터 데모를 실행할 수 있습니다.

[소스와 Docker 실행 안내](https://github.com/kwakhyun/relayguard) / [v0.2.0 릴리스](https://github.com/kwakhyun/relayguard/releases/tag/v0.2.0) / [설계와 한계](https://github.com/kwakhyun/relayguard/blob/v0.2.0/docs/threat-model.md) / [피드백](https://github.com/kwakhyun/relayguard/discussions/2)
